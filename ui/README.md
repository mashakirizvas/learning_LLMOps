# UI (Angular) — готовий

Дві частини на одному екрані, студент їх не змінює:

- **Chat** — тонкий чат: повідомлення, індикатор набору, під відповіддю бота —
  latency і чип інструмента (`🔧 lookup_order`), якщо той викликався.
- **Console** — LLMOps-консоль: 6 плиток (вартість з прогрес-баром бюджету, p95,
  запити, cache-hit, error rate, fallback), картки Prompt registry (з кнопкою
  rollback), провайдери, Approvals (з кнопкою approve). Оновлюється сама кожні 4с.

Консоль читає API-контракт сервісу (`/observability` `/cost` `/prompts` `/providers`
`/approvals`). Поки ендпоінт — заглушка, плитка показує «—»; реалізуєш його в
сервісі — плитка оживає. Кнопки approve/rollback просто викликають POST-ендпоінти
сервісу — фронт логіки не тримає.

Ходить у сервіс через dev-proxy `/api` → `service:8080` (`proxy.conf.json`).
Локальний запуск поза Docker: `npm install && npm start`.
