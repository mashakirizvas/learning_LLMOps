# Mock provider — готовий

OpenAI-сумісний фейковий ендпоінт (`/v1/chat/completions`). Використовується для dev і CI без витрат.

Дві обовʼязкові можливості (від них залежить, що весь core проходиться keyless):

1. **Інжекція збоїв** на замовлення — 503, 429, затримка, сміття у відповіді (для reliability, `docs/failure-scenarios.md`). Керування через заголовки/квері, напр. `?fail=503`, `?delay=5000`.
2. **Вихід залежить від промпта/конфігу** — щоб rule-based evals і CI-гейт ловили регресію: правильний промпт → канонічна відповідь; зламаний → інша, яку grader відбракує.

Реальний ключ провайдера потрібен лише для model-based evals (оцінка справжньої якості), не для core.

Реалізація готова: `Program.cs` (.NET minimal API) + `Dockerfile`. Збої — через `?fail=503&delay=2000&garbage=1` або маркери в повідомленні (`__fail_503`, `__delay`, `__garbage`), щоб працювало й крізь gateway.
